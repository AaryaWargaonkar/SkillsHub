# 🎓 SkillsHub — Full-Stack E-Learning Platform

SkillsHub is a **full-stack e-learning platform** developed using the **MERN stack**. It provides separate experiences for students and instructors, allowing instructors to create and manage courses, lessons, and interactive challenges, while students can browse courses, enroll in free courses or purchase paid courses, learn through lessons, track their progress, complete challenges, earn badges and certificates, and submit course reviews.

---

## 🚀 Features

### 👨‍🎓 Student Features

- Student registration and login
- Browse available courses
- Search and filter courses
- View detailed course information
- Enroll in free courses
- Purchase paid courses through Razorpay Test Mode
- Access enrolled courses and lessons
- Complete lessons
- Automatic course progress tracking
- Interactive lesson challenges and quizzes
- View quiz scores and correct answers
- Submit course reviews and 1–5 star ratings
- View enrolled courses
- View individual course progress
- Earn achievement badges
- Receive course completion certificates
- Manage username, email, and password

### 👨‍🏫 Instructor Features

- Instructor registration and login
- Instructor dashboard
- Create courses
- Edit courses
- Delete courses
- View instructor-owned courses
- Add lessons to courses
- Edit lessons
- Delete lessons
- Add interactive challenge questions
- Delete challenge questions
- View course enrollment statistics
- View student reviews and ratings
- View average course rating
- Reply to student reviews
- Manage instructor profile

### 🏆 Learning & Gamification

- Lesson completion tracking
- Automatic course progress calculation
- Interactive lesson challenges
- Course completion tracking
- Achievement badge system
- Learning milestones
- Course completion certificates

### 💳 Payment

- Support for free and paid courses
- Razorpay Test Mode integration
- Simulated payment workflow for paid courses
- Enrollment after successful payment
